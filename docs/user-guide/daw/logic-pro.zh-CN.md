# Logic Pro 方案

状态：**草案（DRAFT）——尚未实测。** 依据 Apple 的 Logic Pro 使用手册编写；菜单名称须在矩阵测试时按
[../../DAW_COMPATIBILITY.md](../../DAW_COMPATIBILITY.md) 记录的版本逐项确认。通用流程见 [README.zh-CN.md](README.zh-CN.md)，本页只补充 Logic 自己的设置。英文版：[logic-pro.md](logic-pro.md)。

## 1. 音频设备与采样率

* *Logic Pro › 设置 › 音频 › 设备*：输出设备与输入设备 = 你的声卡。
* *文件 › 工程设置 › 音频 › 采样率*：声卡的采样率。Logic 会把声卡切到工程采样率；用同一采样率生成扫频，导入时就不需要转换。

## 2. 导入扫频且不被拉伸

Logic 的 Smart Tempo 会把导入的音频 flex 到工程速度。**导入之前**先在本工程里关掉：

1. *文件 › 工程设置 › Smart Tempo*：**工程速度模式默认：保持工程速度（Keep Project Tempo）**；**将导入的音频文件设为：关（Off）**。
2. *文件 › 导入 › 音频文件…*（或把 WAV 拖到一条空音频轨上）。不要接受采样率转换——如果 Logic 提出转换，说明工程采样率不对，改正后重新导入。
3. 选中区域，在左上角的**区域检查器**（*Region:* 面板，隐藏时按 *I*）确认 **Flex & Follow：关（Off）**。四个取值是 *Off*、*On*、*On + Align Bars*、*On + Align Bars and Beats*，只有 *Off* 不动音频。
4. 确认 **Varispeed** 关闭（控制条上的 Varispeed 按钮若显示，不得点亮）。Varispeed 改变整个工程的播放速度，RoomScope 会报告"错速播放"。
5. 关闭循环（Cycle）。

## 3. 路由与录音

* 轨道 1（扫频）：输出 **Stereo Out**（或送往监听音箱的那对输出）。轨道上不放插件。
* **Stereo Out** 通道条与 **Master** 推子：测量时完全不放插件（没有限制器、没有房间校正或监听插件）。
* 轨道 2：*轨道 › 新建音频轨道*，单声道，**输入：Input M**（链路检查用回环输入，测房间用麦克风输入）。点 **R**（录音预备）。**I**（输入监听）保持**关闭**：开着的话，录音时麦克风信号会被送到监听音箱。
* 把播放头放在扫频区域之前，按 **R**（录音）。扫频结束约三秒后停止。

## 4. 取出录音

**方式 A（最佳）：录音文件本身。** *浏览器 › 工程*（Project Audio 浏览器，*F*）：选中该 take，在音频文件菜单里 *在 Finder 中显示*（或把文件拖到 Finder）。Logic 按 *文件 › 工程设置 › 录音 › 录音文件类型* 以 WAVE、AIFF 或 CAF 录到 *<工程>/Media/Audio Files*；RoomScope 三种都能读。这个文件没经过任何处理。

**方式 B：导出区域。** 选中录下的区域，*文件 › 导出 › 区域作为音频文件…*：

| 选项 | 取值 |
| --- | --- |
| 存储格式 | **WAVE**（AIFF 也可以） |
| 位深度 | **32 位（浮点）**（24 位也可以） |
| 标准化（Normalize） | **关**（不要 *仅过载保护*，不要 *开*） |
| 绕过效果插件 | 开（反正不应该有插件） |
| 包含音频尾音 | 关 |
| 包含音量/声相自动化 | 关 |

不要用 *文件 › 并轨（Bounce）* 做测量：它的默认值包含标准化，而且渲染的是整个混音。

## 5. Logic 特有的陷阱（链路检查失败时对照）

| `roomscope check` 报告的症状 | 要检查的 Logic 设置 |
| --- | --- |
| 被时间拉伸 x % | 区域检查器 *Flex & Follow* 不是 Off；工程设置 › Smart Tempo 的 *将导入的音频文件设为* 不是 Off；轨道的 Flex 按钮开着 |
| 错速播放 x % | Varispeed 开着；工程采样率 ≠ 生成扫频的采样率；导入时接受了采样率转换 |
| 第 k 次谐波 x dB / 响应偏差 x dB | Stereo Out 或 Master 上有插件；*设置 › 音频 › 通用 › 软件监听* 与麦克风轨道的 *I* 同时开着 |
| 在 x dBFS 削波 | 导出时 *标准化：开* 本身不削波，但 *仅过载保护* 会掩盖削波；降低扫频电平或输入增益 |
| n 次播放 | 循环开着，或一个区域里有两个 take |
